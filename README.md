## 📐 Core Engineering Tenets

1. **Zero-Placeholders & Zero-Hallucination:** Production code runs on real failure handling and explicit circuit breakers, never optimistic stubs or unhandled panics.
2. **Separation of Control Plane & Data Plane:** Heavy binary payloads (video, CDP packets) never share bandwidth with latency-critical heartbeats or leases.
3. **Edge Sovereignty & Extreme FinOps:** Eliminating cloud provider lock-in with resilient, self-healing bare-metal edge clusters.
4. **Client-Side Privacy Boundary (Zero-Knowledge):** All telemetry and user signals are scrubbed on-device before touching any external model inference.
